## ▶️ How to Use

### VLC

1. Download the `.m3u` playlist.
2. Open VLC Media Player.
3. Go to **Media → Open File**.
4. Select the playlist.
5. Choose a channel and start watching.

### IPTV Players

The playlist can be used with M3U-compatible IPTV applications such as:

- VLC
- Kodi
- TiviMate
- OTT Navigator
- IPTV Smarters
- Other M3U-compatible players
